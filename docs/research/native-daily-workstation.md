# Fixed native daily workstation

This offline interface uses native-daily-v2 and the fixed DoubleMA quantity
candidate. Five arms (T,TO,B50,B100,C) share one cashbook at5/10bps. Costs are
uncalibrated combined proxies. Engineering outputs do not qualify real data or
financial effectiveness; Paper/live remain unavailable.

## Ordinary startup and no-input workflow

Using an existing installed runtime and a persistent directory outside any
resettable demo root:

```powershell
python -m quantmesh.api.workstation --native-daily-root C:/QuantMesh/native-studies
```

Open `/app/research/jobs`, choose **Native daily · fixed DoubleMA research**.
With no registered package/grant, **Save insufficient evidence** persists an
INSUFFICIENT admission and not_run task, no report and no consumed trial. Save
Reject or Watch with a reason. Retain the displayed study ID or its URL; reopen it
to inspect/download the original admission and decision after restarting the app.
An unavailable persistent store is displayed as unavailable, never a successful
ephemeral save.

## Registered offline substitutes and source facts

Trusted configuration can register existing ObjectRefs through
`RealInput`/`ResearchScope`/`BoundGrant` and `register_bound_input`. There is no
public upload, path input, grant creation or permission boolean. The input binds
source/review and asset references, raw USD prices, share-volume units, historical
venue coverage, supported complete ex/pay actions, calendar/timezone/version,
availability/PIT limitations, exact100+21-session window, sample role, exposure
and trial-ledger references. Candidate grant, scope and separately registered
authority must match. Unknown PIT is recorded as a limit, not invented certainty;
no new SIP/all-market requirement is introduced.

An authored engineering substitute may exercise that adapter and the ordinary
page's report/decision/reopen flow. Actual reviewed-real input execution is
explicitly disabled until separately qualified; merely constructing its manifest
or copying an old grant cannot enable a trial. No instrument/provider/window/OOS
choice is made by this feature. Old SPY/once evidence cannot migrate.

Select the registered package and its grant, then submit the fixed study. The
browser saves UUID/request before POST. After an uncertain reply, read or retry
that identity; do not create another trial. One consumed grant cannot be reused
under another UUID. A completed study remains completed after restart; an
unfinished admitted calculation becomes interrupted and is not rerun/refunded.

View all five arms at each cost, inspect/download original JSON, save one bound
Reject/Watch decision, then reopen the same ID. Reads validate bytes and bindings
without calculation/calendar generation. Reports include generic input facts;
runtime/source identities stay original even after application upgrades.

## Delivery evidence and limits

Issue253 and [the iteration](../iterations/0038-native-daily-real-workstation.md)
track targeted RED/GREEN, ordinary desktop/375px screenshots, exact downloads and
an owned local process restart. The acceptance preview uses current compiled
frontend/dist with ordinary workstation composition; publisher integration of
the committed SPA bundle and applicable CI remain separate release gates.
For source-checkout development, explicitly bind PYTHONPATH to that checkout's
src before generation/launch; do not confuse an unrelated installed editable
worktree with the current source. No new environment or dependency is required.
