# QuantMesh v0.1.1-rc1 — 验收说明（中文辅助）

包版本为 `0.1.1rc1`，候选标签为 `v0.1.1-rc1`。本候选把已验收的
v0.1.0 工作站扩展为按 `venue:symbol` 区分的统一研究到模拟下单工作区，
但不增加任何实盘权限。

## 主要变化

- 单一标的工作区综合历史/实时行情、对比走势、有限指标、7/30/126 交易日
  预测区间、建议证据、模拟持仓、盈亏、风险和审计。
- 数据缺失、陈旧、来源不明或估值不完整时明确降级，不伪造实时行情，也不
  显示虚假的精确资产值。
- 模拟建议必须先预览再人工确认，并受预测、报价、kill switch、journal 与
  恢复一致性约束，不会重复成交。
- 前端支持中英文、明暗主题、键盘与窄屏；前端依赖审计、许可证、API 类型
  和生产 bundle 均纳入发布门禁。

## 验收边界

当前已通过 2,591 项 Python 测试（4 项环境跳过）、143 项前端单元测试、
35 项浏览器 E2E 和 60 项黄金路径检查；TypeScript、lint、API/bundle 新鲜度、
npm 安全审计（0 漏洞）及 646 个锁定前端依赖的许可证检查也已通过。分支的
17 步干净克隆门禁已全部通过（2,592 项通过、4 项环境跳过、黄金路径 60/60、
clone 干净）；发布前还会在合并后的精确标签上再次执行门禁并建立隔离验收环境。
本候选仅允许只读实时数据和本地模拟盘；没有券商凭据、钱包签名、实盘订单、
付费基础设施或 AI 自主下单。只有操作员明确验收后，才可另行提升到
`v0.1.1`。

演示盘重置会原子发布一棵经过验证的新目录，并且绝不在运行时递归删除路径。
为避免 Windows 路径替换导致误删，旧目录会作为隐藏的同级隔离目录保留，并把
路径返回给操作员。因此多次重置会占用额外磁盘空间；请先检查这些目录，再在
工作站停止后人工处理。本候选故意不提供自动递归清理，因为可替换路径无法作为
安全的删除身份。
