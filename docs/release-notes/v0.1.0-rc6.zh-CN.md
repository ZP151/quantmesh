# QuantMesh v0.1.0-rc6 — 发布说明

包元数据 `0.1.0rc6`（PEP 440）在两个来源中一致并由测试固定；标签
`v0.1.0-rc6` 位于已验证的合并提交上。v0.1.0-rc5 保持不可变且不提升：全局
语言/主题偏好切片（PR #97）在 rc5 打标签后合入 main，打包的 SPA 因而变化，
下一候选从合并后的树上切出。本 RC 在已验收的 rc5 基线之上打包全局偏好
迭代（0016）。

## 自 rc5 以来的变更

迭代 0016 — 全局偏好与工作站连续性（PR #97，合并于 `3514c18`）：

- **持久化的全局语言（English / 简体中文）与主题（System / Light /
  Dark）偏好**，应用于壳层、导航、会话横幅、页脚、命令面板与新的设置页。
- **localStorage 持久化（`quantmesh.preferences`）**，`index.html` 内联
  首屏引导（无主题闪烁）、`lang` 与 `color-scheme` 同步、系统主题
  `matchMedia` 监听。
- **类型安全的消息字典**：`MessageKey` 以 `as const` 约束，缺失 zh-CN
  键是 TypeScript 编译错误，而非运行时空白。
- **可访问的设置路由**（`/app/settings`）基于现有 shadcn 风格 token 与
  原生可访问 select；紧凑宽度可用且支持键盘导航。
- **安全措辞经消息表逐字保留** —— demo/live/operator 会话文案、溯源、
  过期数据与纸面安全表述与被评审的英文原文逐字节一致。
- **领域屏幕文案保持已评审的英文回退**，直至各市场/研究/交易界面获得
  翻译字典；金融术语绝不被机器翻译得不一致。
- 重建的打包 FastAPI SPA bundle 随切片提交。

## 安全（不变）

所有 venue 只读；无凭据；无 mainnet、真实资金交易或自主执行；AI 仅
总结/质询；demo 与 live 数据带标签且隔离；纸面订单由报价栅栏把关。
偏好仅存在于浏览器本地，绝不被发送到 venue 或经纪商。`--demo` 会话是
带标签的确定性运行时；`--live` 保持标签为真实。验收本 RC 不提升
`v0.1.0` — 提升仍需单独记录的操作员裁决。
