# QuantMesh v0.1.0-rc4 — 发布说明

包元数据 `0.1.0rc4`（PEP 440）在两个来源中一致并由测试固定；标签
`v0.1.0-rc4` 位于已验证的合并提交上。v0.1.0-rc3 被操作员拒绝
（2026-08-09）：浏览器复评发现两项产品缺陷——Forecasts 页面既未显示
概率，也未显示校准说明；SPA 侧栏硬编码 `rc2`，而 API/包元数据均报告
rc3。操作员在本地修复了这两项缺陷，并通过浏览器验收、kill switch
409 演练、键盘走查与全量测试运行验证了修复；本 RC 打包该修复。
已发布的 `v0.1.0-rc3` 标签是历史记录，不做改写。

## 自 rc3 以来的变更

- **Forecasts 暴露验收证据**（`8f462de`）：每个预测市场卡片现在显示
  最近一次观察到的概率、观察时间戳与流动性置信度，以及明确的校准
  说明（基于已结算测试窗口数量的 Brier 评分，或在无已结算观察时给出
  明确原因——绝不伪造分数），并带有标注来源行（"venue implied
  probability · deterministic seeded observation"）。后端
  `MarketForecast` 模型现在显式保留最新观察
  （`latest_probability`、`latest_probability_at`——要求时区感知并
  校验、`latest_liquidity_confidence`），而非让 API 从历史窗口重建
  当前报价。
- **SPA 侧栏版本来自 API**（`8f462de`）：桌面侧栏与移动抽屉中硬编码
  的 `rc2` 徽章替换为从 `GET /api/health` 读取的 `v{version}`——
  与页脚同一来源；健康检查不可用时诚实回退为 `local`。
- 修复后的前端构建产物已随修复一并提交，打包应用（单进程、运行时
  无需 Node.js）直接提供修复后的界面与 Research 页面。
- 其余与 rc3 相同：React 19 + Vite + Tailwind 4 + shadcn/ui SPA
  （ADR-0013）、带溯源与一键重置的确定性 `--demo` 运行时、完整的
  研究到纸面下单浏览器闭环、免凭证公共数据路径（带标注合成回退）、
  逐行拒绝原因的 CSV/JSON/Parquet 导入、键盘/WCAG 2.2 AA 覆盖，以及
  将标签 == 包版本 == 最新发布说明固定的发布门禁步骤（PEP 440
  比较）。

## 安装

需要 Python 3.13 与 git。

```text
git clone <this repository>
cd QuantMesh
python -m venv .venv
.venv\Scripts\activate        # Windows; on POSIX: source .venv/bin/activate
python -m pip install -e ".[dev,research,e2e]"
```

## 运行 — 演示模式（验收推荐）

```text
quantmesh-workstation --demo
```

然后打开 <http://127.0.0.1:8765/app/>。工作站仅绑定回环地址，运行
确定性种子纸面会话。每个页面显示其溯源；顶栏重置按钮恢复纯净演示
根目录。

## 运行 — 操作员模式

```text
quantmesh-workstation
```

在同一 SPA 上打开操作员状态根（纸面账户初始为空）。演示与导入数据
均被标注并与非演示操作员状态隔离；重置只影响演示根目录。

## 停止与重置

- 停止：在工作站终端按 `Ctrl+C`。
- 演示根目录：使用顶栏重置按钮，或删除配置的 `--demo-root`
  目录。
- 全部生成状态：删除数据根 `~/.quantmesh/`（可通过
  `QUANTMESH_*` 环境变量配置，见 `src/quantmesh/settings.py`）。

## 安全控制（自 rc1 起全部 fail-closed，未变）

- 实盘交易默认关闭（`allow_live_trading: false`），未经明确人工
  批准并记录带有准确门禁文本的启用转换，任何代码路径都不会执行
  真实资金交易、主网钱包签名、实盘经纪商下单、凭证使用、付费
  基础设施或 AI 下单权限。
- 工作站仅绑定回环地址；模型网关默认仅回环端点，除非显式以
  `allow_remote=True` 构造，否则拒绝远程 URL。
- 全局与逐交易所 kill switch 在会计风控门中强制生效，并由 E2E
  演练验证。
- 连接器探测为只读；公共数据路径从不发送凭证（也不存在凭证）。

## 已知限制

- 内部纸面交易所是唯一执行面；本 RC 中 Moomoo 与 Hyperliquid
  适配器仍是只读行情面。
- 免凭证公共路径为演示标的（Hyperliquid）提供最近快照；缺少
  vendored SDK 时降级为标注合成 fixture 行而非失败。
- 预测概率证据为确定性种子观察，并在 UI 中明确标注；实时流式
  概率是下一迭代（Live Market Cockpit）。
- 导入数据集按数据根隔离，演示重置会清空（重置恢复纯净种子根）。
- E2E 测试在存在共享 Playwright 浏览器缓存时运行，否则报告为
  跳过。
