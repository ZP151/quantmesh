# QuantMesh v0.1.0-rc8 — release notes

Package metadata is `0.1.0rc8`; the verified candidate is tagged
`v0.1.0-rc8`. RC7 remains immutable as the release record for the live
research surface, but its operator-start command advertised an unsupported
`--port` argument. RC8 fixes that release-blocking documentation/CLI mismatch.

## What changed since rc7

- `quantmesh-workstation --port PORT` now overrides the loopback port for
  `--demo`, `--live`, and the empty paper workstation. The host remains bound
  to the configured loopback address; non-loopback hosts remain refused.
- Values outside 1–65535 fail at argument parsing. Regression tests cover the
  default settings port, a valid override, and an invalid override.
- The operator command is now executable as documented:

  ```powershell
  quantmesh-workstation --demo --port 8766
  ```

## Included product scope

RC8 includes the global localization and theme settings from PR #100 and the
read-only live research surface from PR #101: bounded watchlists, provenance
and freshness evidence, compact charts, recorded replay, and paper-only order
flows. No live trading, wallet signing, credentials, paid feeds, or AI order
authority is included.

## Verification and known limits

The release gate is run from a clean checkout of the exact candidate tree and
records its current test counts in `docs/goals/ACTIVE.md`. Browser acceptance
uses deterministic demo data only. Live mode remains read-only and can show
unavailable or degraded venues when public feeds or local OpenD are absent.

Promotion to `v0.1.0` requires a recorded acceptance verdict; this RC does not
itself authorize live-market execution.
