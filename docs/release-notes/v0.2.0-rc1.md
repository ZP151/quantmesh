# QuantMesh v0.2.0-rc1 — reproducible research workstation

Package metadata is `0.2.0rc1`; the candidate tag is `v0.2.0-rc1`.
The tag, if created, identifies the exact verified `main` commit. This
candidate presents the current local research workstation as one bounded
operator-facing capability line; it does not enable real-money trading.

## Operator capabilities

- Start a credential-free local demo and inspect the workstation with
  explicitly synthetic data.
- Import local market data with visible provenance and qualification status;
  inspect bounded read-only market observations when a feed is configured.
- Run bounded research jobs and reopen saved reports or frozen experiment
  evidence. Active vn.py jobs do not resume after a process restart.
- Inspect decision evidence and guarded Paper controls. Paper is the default;
  live execution remains disabled without its separate approval gates.
- Use optional labelled Advisory explanations as research input, never order
  authority. An unavailable or unverified model response is not presented as
  a successful real model call.

## Reproducible install

Use Python 3.13 and the Quickstart in the repository README. The release gate
installs `.[dev,research,e2e,moomoo]` in a fresh checkout; the ordinary demo
uses the base package. vn.py is an optional external runtime with its own
installation and license boundary.

## Verification and limits

The exact candidate commit, release-gate counts, browser and operator verdict,
and tag status must be recorded in the publication receipt before this RC is
offered for acceptance. This notes file alone does not certify them.

The previously captured SPY sample is not qualified for real-data claims:
historical volume units and feed coverage remain unresolved. Parser
compatibility does not establish input qualification. BTC feed acceptance is
bounded to its observed window, and market feeds may be unavailable. Advisory
effect remains `UNKNOWN` with a USD 1 budget. No performance or profitability
claim follows from synthetic demonstrations.
