# QuantMesh v0.1.0-rc8 — 发布说明（中文辅助）

包版本为 `0.1.0rc8`，验证后的候选标签为 `v0.1.0-rc8`。RC7 保留为实时研究界面的历史发布记录；但其验收启动命令写出了尚未实现的 `--port` 参数。RC8 修复该发布阻塞问题。

## 相比 rc7 的变化

- `quantmesh-workstation --port PORT` 可为 `--demo`、`--live` 和空白模拟工作站覆盖回环端口；主机仍严格绑定到配置的本机回环地址，非回环绑定仍会被拒绝。
- 端口必须在 1–65535；默认端口、合法覆盖和非法覆盖均有回归测试。
- 验收命令现在可以按文档直接运行：

  ```powershell
  quantmesh-workstation --demo --port 8766
  ```

## 已包含的产品范围

RC8 包含 PR #100 的全局语言和主题设置，以及 PR #101 的只读实时研究界面：有界自选、来源/新鲜度证据、紧凑图表、记录回放和仅模拟盘的订单流。未加入实盘交易、钱包签名、凭据、付费数据源或 AI 下单权限。

正式提升到 `v0.1.0` 仍需要记录的验收结论；本候选不会授权任何实时市场执行。
