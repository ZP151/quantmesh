# QuantMesh v0.1.0-rc1 验收指南（中文）

本指南面向操作员（operator）：安装、启动、演示、停止/重置、
安全控制、已知限制，以及一份可直接执行的验收清单。全部命令在本
仓库根目录执行；发布提交与验证计数见「发布验证」一节。

## 1. 安装

要求：Python 3.13 与 git。

```text
git clone <本仓库>
cd QuantMesh
python -m venv .venv
.venv\Scripts\activate        # Windows；POSIX 用 source .venv/bin/activate
python -m pip install -e ".[dev,research,e2e]"
```

安装的就是发布闭包（64 个锁定依赖，含研发/端到端扩展）；许可证
门禁与依赖审计都针对该闭包。

## 2. 启动

```text
quantmesh-workstation
```

然后打开 <http://127.0.0.1:8765>。工作站只绑定回环地址（绑定
非回环地址会在构造时被拒绝），并以全新空纸面账户启动——绝不会
发出真实订单。

13 个页面：总览 / 自选列表 / 跨市场标的 / 持仓 / 订单 / 盈亏 /
实验对比 / 策略晋级 / 预测报告 / 风险 / 审计 / 全局与分市场急停
开关 / 启停审批台账。

## 3. 演示（黄金路径）

```text
python tools/golden_path.py
```

执行：fixture 数据 → 数据湖 → 策略报告 → 内部纸面交易 → 13 个
页面全部渲染（首次启动与重启后各一遍，端口 8643/8644）→ 重启
恢复（订单日志回放）→ 每个审计台账重新读取。逐项打印 PASS/FAIL，
使用临时状态目录，结束后仓库保持干净。

## 4. 停止 / 重置

- 停止：在工作站终端按 `Ctrl+C`。
- 重置全部生成状态：删除数据根目录 `~/.quantmesh/`（可用
  `QUANTMESH_*` 环境变量改路径，见 `src/quantmesh/settings.py`）。
- 仓库本身不写任何运行时数据；黄金路径只写它自己的临时目录。

## 5. 安全控制（全部默认拒绝）

- 实盘交易默认关闭（`allow_live_trading: false`）。任何真实资金
  交易、主网钱包签名、真实经纪商订单、凭据使用、付费基础设施、
  AI 下单权限，都必须先获得明确的人工批准，并在启用台账中记录
  携带逐字门禁文本的启用迁移。
- 工作站仅绑定回环；模型网关默认回环端点，非回环地址需显式
  `allow_remote=True` 构造。
- 全局与分市场急停开关在会计风险门中强制生效，并由 E2E 演练
  验证。
- 启用台账记录每一次 request/approve/withdraw/revoke 迁移（含
  行为人与时间）。

## 6. 已知限制

- 本 RC 唯一执行面是内部纸面 venue；Moomoo 与 Hyperliquid 适配器
  仅为只读行情面。
- Moomoo OpenD 模拟账户与 Hyperliquid 测试网演练是可选的操作员
  验证，不属于本 RC 验收项。
- 共享 Playwright 浏览器缓存存在时 E2E 用例运行，否则报告为
  skipped；黄金路径不依赖浏览器。
- 非 Linux 平台：6 个 Linux-only 闭包成员（uvloop、jeepney、
  SecretStorage、cryptography、cffi、pycparser）固定锁定并允许
  缺席。
- 发布门禁约需 15 分钟，且全新安装需要可用网络。

## 8. 验收清单（可逐条执行）

| # | 项目 | 命令 / 动作 | 通过标准 |
|---|------|------------|---------|
| 1 | 全新安装 | 第 1 节命令 | 安装成功，无错误 |
| 2 | 版本一致 | `python -c "import quantmesh; print(quantmesh.__version__)"` | 输出 `0.1.0rc1` |
| 3 | 黄金路径 | `python tools/golden_path.py` | 全部 PASS，退出码 0 |
| 4 | 启动工作站 | `quantmesh-workstation`，打开 8765 端口 | 13 个页面可访问 |
| 5 | 重启恢复 | 黄金路径的 restart 段 | 账户/台账从同一数据根恢复 |
| 6 | 安全控制 | 页面「Kill switch / Enablement」 | 默认拒绝、需人工批准记录 |
| 7 | 停止/重置 | `Ctrl+C`；删除 `~/.quantmesh` | 干净退出，可再次启动 |
| 8 | 完整门禁 | `python tools/release_gate.py`（可选，约 15 分钟） | RELEASE GATE PASSED |

验收通过后，元数据与标签将提升为 `v0.1.0`；如有缺陷，在此记录
并发布下一个 RC，不扩大产品范围。
