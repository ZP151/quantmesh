# QuantMesh v0.1.0-rc7 — 发布说明

版本元数据 `0.1.0rc7`（PEP 440），源码与测试均锁定一致；
标签 `v0.1.0-rc7` 打在已验证的合并提交上。v0.1.0-rc6 保持
不可变且不被晋升：迭代 0019 的实时研究界面（PR #101）在 rc6 
打标后合并入 main，打包的 SPA 已变更，因此从合并树中切出
下一个候选版本。此 RC 在 rc6 基线（全局本地化、全局偏好、
工作站连续性）之上打包了迭代 0019 的实时研究改进。

## 自 rc6 以来的变更

迭代 0019 — 实时研究界面（PR #101，合并于 `298825b`），
6 个子切片覆盖全部 4 个范围项：

### 1. 统一实时看板与筛选模型

- 单一观察列表表格，包含：交易品种、市场、来源标签、
  买价、卖价、中间价、价差 bps、最新成交价、事件/接收时间、
  序号、新鲜度及每行价格趋势迷你图。
- **筛选模型**：带搜索图标和清除按钮的搜索框，按品种或
  市场名称筛选，客户端执行，不区分大小写，无匹配时显示
  诚实的空状态行。

### 2. 研究级指标

- Hyperliquid 资金费率、标记价格、指数价格、未平仓合约、
  标记-指数偏离、短窗口回报、已实现波动率、K线成交量、
  成交规模、买卖盘深度——均来自市场提供的 `metrics` 和
  `candle` 帧，UI 中绝不估算或合成。
- 每个指标都带有证据边界（事件时间、接收时间、序号、新鲜度、
  来源属性），来自标准化 `MarketUpdate` 合约。

### 3. 图表与密度

- **紧凑型 SVG 买卖盘深度图**：两侧深度以堆叠 SVG 矩形
  渲染，买/卖颜色区分，按中间价范围缩放——无图表库依赖
  （沿用现有 SVG 边界）。
- **成交带**：按买卖方向渲染的成交记录，带颜色区分，
  能感知序号，来自实时流。
- **价格趋势迷你图**：每行 80×24 的 SVG 折线图，显示
  近期 K线收盘价——绿色线条，按行的价格范围缩放，
  数据点不足 2 个时隐藏。数据来自
  `GET /api/live/price-trail?symbols=...` 通过 DuckDB
  回放数据湖（`LiveBuffer.price_trail`，每个品种独立
  `QUALIFY ROW_NUMBER()` 截取）。

### 4. 回放与运维测试

- **已录制回放工作流**：驾驶舱内「已录制回放」卡片显示
  数据湖范围（数量、最早/最新接收时间、市场）；提供
  5 分钟 / 15 分钟 / 全部窗口操作；在醒目的紫色「回放模式」
  横幅下显示已回放的行（含窗口边界、更新数量、`来源：数据湖`），
  并有清除操作。回放严格只读——绝不混入实时缓存或纸面交易。
- **运维测试**：覆盖审计确认健康/停止（实时烟雾测试）、
  延迟/来源（监管器阶梯）、丢帧（背压门 + 序号缺口测试）、
  重连（`TestDisconnectDrill` + 回放折叠），以及回放窗口和
  价格轨迹 API 的新端点级测试。
- **浏览器验收**：回放卡片诚实性（无数据湖时的故障闭合）
  E2E，新增 768px 平板无溢出检查——浏览器 E2E 7/7。

### 5. 全局本地化完成（PR #100, `5069d1b`）

- 完成剩余屏幕级别的翻译：预测、紧急停止、启用、未找到、
  加载、外壳无障碍/来源属性文案——使用共享的 en/zh-CN
  消息字典。
- API 返回值和服务安全判定保持原始语义，不翻译。

## 安全性（不变）

所有市场只读；无凭证；无主网、实盘交易或自主执行；
AI 仅限总结/质疑；演示和实时数据均已标记和隔离；
纸面交易受报价围栏保护。偏好设置存储于浏览器本地，
绝不发送至市场或经纪商。`--demo` 会话为标记的确定性
运行时；`--live` 保持标记为真实。回放数据严格只读，
绝不混入实时缓存或纸面交易界面。接受此 RC 不代表晋升
`v0.1.0`——晋升仍需单独记录的操作员裁决。
