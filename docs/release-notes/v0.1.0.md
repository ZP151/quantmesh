# QuantMesh v0.1.0 — first accepted local release

This release promotes the operator-accepted RC8 candidate without changing its
product scope. The verified commit includes a deterministic paper workstation,
global English/简体中文 and theme preferences, bounded cross-market research,
provenance and replay surfaces, and a tested loopback `--port` override.

## Verification

- RC8 clean-checkout release gate: 15/15 passed, including security checks,
  frontend tests, browser E2E, full pytest, golden path and clean checkout.
- Delegated operator acceptance: deterministic demo labels, global language and
  theme persistence, paper order fill, and kill-switch engage/disarm verified.
- Formal v0.1.0 release gate is rerun from the exact promotion tree before the
  `v0.1.0` tag is created.

## Safety boundary

All venues remain read-only or paper-only. This release does not enable
real-money orders, wallet signing, credentials, paid infrastructure, cloud
deployment, or AI order authority.
