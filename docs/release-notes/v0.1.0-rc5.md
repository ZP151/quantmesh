# QuantMesh v0.1.0-rc5 — release notes

Package metadata `0.1.0rc5` (PEP 440) in both sources and pinned by the
tests; tag `v0.1.0-rc5` on the verified merge commit. v0.1.0-rc4 is not
promoted: the operator-authorized 2026-08-10 acceptance review of the
iteration 0015 cockpit found four release-candidate gaps and the repaired
candidate is newer than the immutable rc4 tag, so rc4 stays a historical
record (issue #94). This RC packages the acceptance hardening and
supersedes the Phase G self-acceptance record.

## What changed since rc4

The post-Phase-G acceptance hardening (issue #94, merged via PR #95 at
`c47b83d`):

- **Instrument detail hydrates the latest snapshot** — `/app/cockpit/:symbol`
  listened only for future stream frames, so a disconnected source showed an
  empty detail page even when `/api/live/state` held a latest
  quote/trade/book. The detail screen now hydrates and periodically
  reconciles that snapshot (10 s) before stream updates.
- **Runtime-honest shell and overview** — the shell always queried
  `/api/demo/status` and Overview claimed all data was synthetic even in
  live mode. `/api/health` now reports `runtime_mode` (demo/live/operator);
  the demo query is disabled outside demo; shell/footer copy is mode-aware;
  live Overview explicitly separates the paper ledger from the cockpit.
- **Fail-closed live smoke contract** — `tools/live_smoke.py` accepted an
  error health status and incomplete state/status shapes. It now fails
  closed on health status, timezone-aware timestamps, payload objects,
  venue/instrument identity, kind-map honesty, empty non-unavailable kinds
  and empty venue surfaces.
- **Inclusive append boundary for replay** — timestamp-only replay could
  not distinguish two appends with the same `received_at`;
  `LiveBuffer.replay(through_local_seq=...)` is the inclusive boundary
  returned by `append`, so every intermediate state is reproducible.
- **Workstation E2E bootstrap race fixed** — the legacy suite checked fixed
  port 8642 and released the probe before uvicorn bound it; the fixture now
  hands uvicorn an already-bound OS-reserved loopback socket (16/16, no
  check-then-bind window). The DuckDB timezone regression was strengthened
  (connection opened in `America/New_York`, constructor pins UTC) and the
  expected fixture cancellation no longer leaks as a pytest thread warning.
- The rebuilt packaged SPA bundle is committed with the fixes.

## Safety (unchanged)

All venues read-only; no credentials; no mainnet, real-money trading or
autonomous execution; AI summarize/challenge only; demo and live data
labeled and isolated; paper orders gated by the quote fence. The `--demo`
session is the labeled deterministic runtime; `--live` stays labeled real.
Acceptance of this RC does not promote `v0.1.0` — promotion still requires
the separate recorded operator verdict.
