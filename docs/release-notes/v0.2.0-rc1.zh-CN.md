# QuantMesh v0.2.0-rc1 — 可复现研究工作台

包版本为 `0.2.0rc1`，候选标签为 `v0.2.0-rc1`。如创建标签，它将指向经过
验证的 `main` 精确提交。这个候选版展示当前本地研究工作台的一组有边界的
用户能力，不开启真实资金交易。

## 用户能力

- 无凭据启动本地演示，查看明确标记为合成的数据。
- 导入本地市场数据并查看来源与资格状态；配置数据源后，可查看有边界的
  只读行情观测。
- 运行有边界的研究任务，重新打开已保存的报告或冻结实验凭据。进程重启后，
  正在运行的 vn.py 任务不会续跑。
- 查看决策凭据和受保护的 Paper 控制。Paper 为默认模式；真实交易仍受
  单独的批准关卡约束。
- 将可选且有标记的 Advisory 解释用作研究输入，不能用作下单权限。
  不可用或未经验证的模型响应不得表述为真实模型调用成功。

## 可复现安装

使用 Python 3.13，按仓库 README 的快速启动步骤操作。发布检查在全新检出中
安装 `.[dev,research,e2e,moomoo]`；普通演示仅需基础包。vn.py 属于可选的
外部运行时，有独立的安装与许可证边界。

## 验证与限制

在提供这个候选版供验收前，发布凭据必须记录精确候选提交、发布检查计数、
浏览器及操作验收结论，以及标签状态。本文件本身不能代替这些凭据。

此前采集的 SPY 样本尚不具备真实数据资格：历史成交量单位和数据源覆盖范围
仍未厘清。解析器兼容不等于输入合格。BTC 数据源验收仅覆盖已观测时段，
行情源可能不可用。Advisory 的效果仍为 `UNKNOWN`，预算上限为 1 美元。
合成演示不构成策略表现或盈利声明。
