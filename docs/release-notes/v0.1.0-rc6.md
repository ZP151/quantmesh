# QuantMesh v0.1.0-rc6 — release notes

Package metadata `0.1.0rc6` (PEP 440) in both sources and pinned by the
tests; tag `v0.1.0-rc6` on the verified merge commit. v0.1.0-rc5 remains
immutable and is not promoted: the global language/theme preference slice
(PR #97) merged into main after rc5 was tagged, so the packaged SPA changed
and the next candidate is cut from the merged tree. This RC packages the
global preferences iteration (0016) on top of the accepted rc5 baseline.

## What changed since rc5

Iteration 0016 — Global Preferences and Workstation Continuity (PR #97,
merged at `3514c18`):

- **Persistent global language (English / 简体中文) and theme
  (System / Light / Dark) preferences**, applied to the shell, navigation,
  session banners, footer, command palette and the new Settings page.
- **Local-storage persistence under `quantmesh.preferences`** with an inline
  first-paint bootstrap in `index.html` (no theme flash), `lang` and
  `color-scheme` synchronization, and a system-theme `matchMedia` listener.
- **Type-safe message dictionary**: `MessageKey` is `as const`-keyed, so a
  missing zh-CN key is a TypeScript error, not a runtime blank.
- **Accessible Settings route** (`/app/settings`) built on existing
  shadcn-style tokens with native accessible selects; responsive at compact
  widths and keyboard-navigable.
- **Safety wording preserved verbatim** through the message table — demo/
  live/operator session copy, provenance, stale-data and paper-safety
  statements are byte-identical to the reviewed English originals.
- **Domain-screen copy stays on the reviewed English fallback** until each
  market/research/trading surface receives a translation dictionary;
  financial terminology is never machine-translated inconsistently.
- The rebuilt packaged FastAPI SPA bundle is committed with the slice.

## Safety (unchanged)

All venues read-only; no credentials; no mainnet, real-money trading or
autonomous execution; AI summarize/challenge only; demo and live data
labeled and isolated; paper orders gated by the quote fence. Preferences
are browser-local and are never sent to a venue or broker. The `--demo`
session is the labeled deterministic runtime; `--live` stays labeled real.
Acceptance of this RC does not promote `v0.1.0` — promotion still requires
the separate recorded operator verdict.
