# Desktop workflow and language refinement — issue306

## Intent and authority

The operator explicitly requested a global desktop UI/UX upgrade and unified
language, with business-driven expansion/collapse, normal CI/merge/publication,
and usable Web entry points. The operator approved two independent Impeccable
assessments. The previously presented design proposal is the layered hierarchy
in VIDEO-LIBRARY-REVIEW-ZH.md: visible task/qualification summary, focused current
operation, discoverable complete evidence. This specification makes that request
executable; detailed layout choices below are the UI implementer's decisions,
not invented human approvals of individual controls.

Issue: https://github.com/ZP151/quantmesh/issues/306.
Source baseline: merged cf77067ac4c936a522e9ee4cfc7761c2b3004c3a.
Operate mode; refine the existing black/graphite/restrained-green, Geist,
separator-first Base UI workstation. No new visual identity or library migration.

One operator action: open a current or saved research context, identify its
qualification and current next step, inspect the needed evidence, and return to
the decision without traversing an evidence transcript or switching languages.

## Approaches and choice

1. Retain every section expanded and tighten spacing. Low implementation cost,
   but the 5546px evidence column and simultaneous tasks remain. Rejected.
2. Put the entire workflow in a mandatory wizard. Shorter screens, but hides
   cross-checks, disrupts saved links and imposes irrelevant steps. Rejected.
3. Preserve the workspace and add task-aware progressive disclosure, readable
   summaries and shared semantic copy. Chosen implementation of the operator's
   requested balance. Essential evidence remains visible; technical detail and
   optional tools remain independently reachable.

## Layout and disclosure contract

- Shell: retain recognizable groups and search/command navigation. Long
  operational navigation may collapse, with active routes discoverable and
  meaningful instrument/research headings. Keep kill-switch and runtime/source
  state available from the shell. Do not change routes or their permissions.
- Workspace: give the market and current decision usable desktop width. Replace
  the very long narrow evidence transcript with a compact evidence summary and
  named detail groups. Keep source/as-of, synthetic status, qualification, costs,
  benchmark identity and every material blocker visible.
- Detailed provenance, full digests and chronology use keyboard-operable native
  disclosure. Forecast metrics expose one readable horizon summary at a time,
  with all original horizons/paths still available. No clipping or artificial
  maximum document height; no evidence scroll jail as a substitute for hierarchy.
- Keep scenario summaries scannable. Optional Copilot, monitoring and outcome
  review start concise, retaining an explicit status/next step when closed.
  Preserve mounted child state and existing query/mutation ownership. Expanding,
  collapsing, changing language or navigating sections must not submit anything.
- Saved research opens on the result/decision context. Keep uncertain-response
  recovery direct when uncertainty exists. Archive management and manual ID
  reopening are subordinate named tools; candidate/state/time precede UUIDs.
- Existing import/readiness, replay, trend and audit progressive-disclosure
  behavior is preserved and brought under common copy/interaction conventions.
  Never collapse away failed admission, original conflicts or material reasons.

## Unified language contract

- Keep the one existing browser preference and supported locales en/zh-CN.
- Extend the typed shared message system, with domain catalogs where useful.
  Move page-local dictionaries and fixed bilingual chrome into this mechanism;
  do not build a second locale store or translate the DOM after rendering.
- One selected locale controls primary labels, known states/errors, navigation,
  date/time and numeric formatting. Stable financial units, symbols, technical
  proper names and original identifiers retain their values.
- Known evidence meanings receive reviewed semantic labels. Exact raw codes,
  source sentences, IDs, digests and timestamp originals remain in accessible
  Original evidence details, not only hover titles. Unknown authoritative text
  remains verbatim with a localized introduction; never invent its meaning.
- Retain full numeric values and ISO timestamps in originals. Display formatting
  changes no computations, rounding inputs, evidence bytes or ordering policy.
- Acknowledged synthetic/engineering pass must read as engineering evidence with
  financial qualification still insufficient. It cannot become generic success
  or qualify real data, out-of-sample research, Paper or live trading.

## Scope and prohibitions

Frontend presentation/semantic copy/shared formatting and their tests, owned
specification/plan/iteration records, and Publisher's standard generated bundle.
No backend/API schema/client/protocol changes; no changes to calculations,
admission, grants, policy, artifacts, risk, idempotency or recovery semantics.
No new dependency, Pro purchase, paid asset, bulk registry installation or iframe
embedding of third-party demos. Six libraries are references only unless a
specific reusable item is separately verified and justified in REUSE_MATRIX.

Desktop Web only: 1280,1440 and the supplied1912 viewport as relevant. No mobile
work. Port8878 and existing service ownership are untouched. No provider, SDK,
model, research execution, business submission or trading action during browser
verification. Use existing synthetic/retained data, correctly labeled.

Use the existing owned checkout and registered resource purpose. Preserve all
old failures/UNKNOWN/future holds. The Root's extra headless48MiB remains a
conservative hold, not a reason to create profiles or claim actual usage.

## Acceptance and release

- Initial saved-packet desktop layout substantially reduces the measured5546px
  page without losing essential evidence; target at most2200px at1440/1912 when
  optional detail groups are closed. Report actual measured height, not a claim
  based on CSS. Expanded originals remain readable with no document overflow.
- Current qualification/phase/source, material blockers and the decision path
  are discoverable without scrolling through full provenance or review forms.
- Locale switches update primary chrome/status/error/date/number presentation;
  originals, request identities, drafts and selected research remain intact.
- Keyboard disclosures and section jumps work; warnings do not rely on color.
  Check desktop reduced motion and a representative zoom/long-string state.
- Meaningful affected tests cover behavior and preservation of safety/identity;
  run frontend type/lint/build and required normal integration gates. No old
  research acceptance or mobile suite is repeated for presentation changes.
- Independent review and one bounded desktop render batch, one consolidated
  correction and confirmation as needed. Publish through the sole Publisher's
  normal PR/CI/squash merge. Runtime owner serves the reviewed merged-equivalent
  bundle and preserves original stored state. Final handoff supplies actual URL,
  source identity and desktop verification, with engineering qualification limits.
