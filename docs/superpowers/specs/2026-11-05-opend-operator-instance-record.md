# OpenD per-instance Operator records (issue 281)

The Operator may restore the same approved logical service under a fresh immutable data instance without publishing code for each nonce. The plan derives all instance paths from one exact lower-case 32-hex nonce. Staging, eab, c8 and the original 4ae v1 restore retain their historical definitions. These three historical persistent identifiers cannot be v2 instances.

The root registry /etc/quantmesh/opend/operator-restores/<nonce>.json is root-owned, single-link, 0444 and bounded to 8192 bytes. The v2 schema qm.opend.operator-restore.v2 preserves the original authority SHA-256, complete persistent claims and closed keys. The claims nonce must agree with the filename and service unit. A selected malformed or inaccessible file refuses without fallback; a historical selection accepts only the matching legacy nonce. Startup verifies the current published launcher and other original sources, actual host and service identities, window, immutable reload and the exclusive single-link claim. The root creates a fresh window just before dispatch and separately verifies the service account can traverse the root:service-GID 0750 registry. Expiry applies to startup, not the subsequent until-operator-stop session.

The released pane sends the 14-field (schema plus 13 fields) qm.opend.attributed-launch.v2 packet to /run/quantmesh-opend-restore-<nonce>.sock. Binding to the root peer, durable-attribution-before-BOUND, held claim and actor custody are required. Root-owned canonical originals live under /var/lib/quantmesh-opend-operator-restores/<nonce>/. OPERATOR-LOGIN-ORIGIN.json (qm.opend.operator-login-origin.v2) permits strict pre-input attribution only. PROVIDER-BINDING.json (qm.opend.provider-binding.v2) additionally requires the sole vendor-owned loopback listener at 11112. Both embed the v2 launch packet. The signatures of the two validators and two read-only snapshot APIs remain fixed. The returned binding exposes its validated nonce; it accepts no caller path.

No mutable CURRENT, service-management or SDK authority is added to the collector. The original private source candidate, five UNKNOWN outcomes and expired control are immutable. Actual service-account traversal, publication, startup, login and endpoint evidence belong to the Operator.
